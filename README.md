# ReddyPanel.in — Premium White Label Platform

A modern, high-aesthetic showcase and multi-link WhatsApp inquiry platform for **ReddyPanel.in** ([reddypanel.in](https://reddypanel.in)).

## Features

### Public Website & Brand Showcase
- **Dark Luxury Aesthetics**: Sleek dark mode with gold accents, glowing gradients, and glassmorphism.
- **Curated & Deduplicated Brands**: Exactly one canonical link per brand/company with whole integer ceiling sharing rates starting from **7%**.
- **VIP Direct Access Portals**:
  - Lotus Plays 365 Agent Portal (`https://ag.lotusplays365.com`)
  - Sport Play 99 Admin Portal (`https://admin.sportplay99.win`)
- **Multi-Brand Selection**: Interactive cards with quick selection toggles, select-all, and clear buttons.
- **Sticky Selection Bar**: Floating bottom action bar that tracks selected brands and enables 1-click WhatsApp order generation.
- **WhatsApp Inquiry & Order System**:
  - Live chip tags for selected brands (with instant delete / custom add).
  - Customizable client inquiry form (Name, Phone, Hierarchy Role, Target Sharing, Functions & Capabilities, Requirements).
  - **Live WhatsApp Chat Preview**: Real-time formatting of the exact message to be sent to WhatsApp without raw asterisk clutter.
  - Direct WhatsApp & Mobile Support dispatch (`+1 7788260166`).
- **Dynamic Search & Filtering**:
  - Live search across brand names and URLs.
  - Sharing rate tier filters (`≤ 10%`, `11%–15%`, `16%+`).
  - Sort by Name, Sharing Low → High, and Sharing High → Low.
- **Welcome Modal**: Session-aware welcome popup highlighting key offerings.
- **Direct WhatsApp Buttons with Custom Pre-filled Inquiries**:
  - Header WhatsApp button
  - Welcome Modal button
  - CTA Launch banner
  - Floating WhatsApp button
  - Footer support link
- **Fully Responsive & Zero Overflow**: Mobile-friendly navigation, sticky action bar, and responsive grids.
